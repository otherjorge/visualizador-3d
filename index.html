Publicação

Para publicar daqui (PC ou celular), o site precisa de uma chave do GitHub da conta dona do site. A chave fica guardada só neste aparelho e não aparece mais depois de salva.

  1. Entre em github.com com a conta do site e abra Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Nome: visualizador-3d. Validade: até 1 ano. Repository access → Only select repositories → .
  3. Permissions → Repository permissions → Contents: Read and write. Gere e copie a chave.
  4. Cole abaixo e toque em Salvar.
